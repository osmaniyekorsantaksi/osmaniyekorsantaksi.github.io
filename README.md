# Osmaniye Korsan Taksi

Osmaniye korsan taksi yolcusu iki terminal arasında seçim yapar. Merkez, Kadirli ve Toprakkale Çukurova'ya yönelir; Osmaniye merkezden 129 kilometre, 1 saat 32 dakika. Bahçe, Hasanbeyli ve Düziçi için Gaziantep Havalimanı daha yakındır; Bahçe'den 121 kilometre tutar.

Karatepe-Aslantaş açık hava müzesi ve Kastabala antik kenti günübirlik gezilir. Yaz sıcağında Zorkun Yaylası'na çıkanlar için sabah ve akşam seferleri olur. Organize sanayideki demir çelik tesislerinin personeli vardiya saatinde araç ister.
